## Как работает сервер

При регистрации пользователь передаёт email и пароль. Сервер хранит хеш пароля, а при успешном входе выдаёт подписанный JWT в поле `jwt`. Middleware проверяет Bearer-токен до передачи запроса в маршруты пользователей и карточек. Для удаления карточки контроллер сравнивает её владельца с идентификатором из проверенного токена.

| Технология | Что делает в проекте |
| --- | --- |
| Node.js и Express | Обработка REST-запросов и общий обработчик ошибок |
| MongoDB и Mongoose | Хранение пользователей и карточек, валидация моделей |
| Celebrate и Joi | Проверка тела запроса и параметров маршрута |
| JWT и bcryptjs | Авторизация и хеширование паролей |

## Маршруты

| Группа | Доступные действия |
| --- | --- |
| `POST /signup`, `POST /signin` | Регистрация и вход |
| `GET /users`, `GET /users/me`, `GET /users/:id` | Список пользователей и профиль |
| `PATCH /users/me`, `PATCH /users/me/avatar` | Изменение имени, описания или ссылки на аватар |
| `GET /cards`, `POST /cards`, `DELETE /cards/:cardId` | Лента, создание карточки и удаление своей |
| `PUT /cards/:cardId/likes`, `DELETE /cards/:cardId/likes` | Установка и снятие лайка |

Например, запрос к локальному серверу с токеном тестового пользователя (переменная shell `TOKEN`)

```sh
curl -H "Authorization: Bearer $TOKEN" http://localhost:3000/cards
```

Для пустой ленты сервер возвращает `{"data":[]}`. Контракты маршрутов и обработчики можно посмотреть в [routes/](routes/) и [controllers/](controllers/).

## Локальный запуск

1. Запустите локальную MongoDB. В корне репозитория создайте `.env` по [.env.example](.env.example).
2. Укажите `DATABASE_URL` для локальной базы и собственный `JWT_SECRET` длиной не менее 32 символов. При необходимости задайте `PORT` (по умолчанию 3000).
3. Установите зависимости и запустите сервер.

```sh
npm ci
npm start
```

Для разработки с перезапуском при изменениях используйте `npm run dev`.

## Тестирование

`npm test` проверяет отклонение некорректных входных данных, валидацию URL в моделях и сокрытие внутренних деталей ошибки. Эти проверки не требуют MongoDB. `npm run lint` запускает ESLint. Для сквозного сценария регистрации и сохранения карточки нужна отдельная тестовая база.

В манифесте проекта указана лицензия ISC. [package.json](package.json)
